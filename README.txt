A SMS — Dark Persian UI Patch

این بسته پوسته تیره، رنگ‌بندی و افکت‌های شیشه‌ای برنامه را بازطراحی می‌کند،
حالت تاریک را پیش‌فرض می‌کند و چند متن اصلی چت را فارسی می‌کند.
هیچ قابلیت آنلاین یا سرویس اینترنتی به برنامه اضافه نمی‌شود.

نصب:
1) فایل ZIP را در ریشه پروژه iMessageLocal استخراج کنید.
2) در Termux از ریشه پروژه اجرا کنید:
   bash ./apply_patch.sh
3) سپس:
   git status --short

این بسته طرح تصویری شش‌تایی را پیکسل‌به‌پیکسل بازسازی نمی‌کند؛ چون خود تصویر
در لینک اشتراکی قابل دریافت نبود. این نسخه بازطراحی تیره و فارسی بر پایه
سورس واقعی فعلی پروژه است. قبل از انتشار، بیلد GitHub Actions را بررسی کنید.
