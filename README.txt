A SMS — Source Update

این بسته شامل فایل‌های منبعی است که در این مرحله تغییر کرده‌اند.
ساختار مسیرها از ریشه پروژه حفظ شده است؛ فایل‌ها را در ریشه مخزن استخراج کنید.

فایل‌های تغییرکرده:
- AndroidManifest.xml: نام نمایشی برنامه به A SMS تغییر کرده است.
- ConversationListScreen.kt: عنوان، شمارنده، جستجو و گزینه‌های فهرست گفتگو فارسی و نمادگذاری شده‌اند.
- SettingsScreen.kt: تنظیم سیم‌کارت، صدای اعلان، انتقال تاریخچه، مجوزها و بخش درباره سازنده.

سایر فایل‌های پروژه عمداً دست‌نخورده‌اند تا منطق دریافت/ارسال پیامک، پایگاه داده و وضعیت تحویل فعلی حفظ شود.
این بسته هنوز به معنی تأیید build نیست؛ پس از استخراج، باید GitHub Actions پروژه اجرا شود.
